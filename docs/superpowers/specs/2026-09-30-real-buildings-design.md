# 신창 실사 기반 건물·랜드마크 설계

**근거:** 사용자 요청 "①절차적·②항공사진·④사진 참고 모델링, 높이 상자 금지", [건물 3D 원천 조사](../../../exa-results/jeju-real-building-3d-sources-2026-09-30.md)(공개 원천 중 신창 실사 3D 없음, VWorld 3D 저장 금지), 현재 `renderers/twin/build_local.py`의 `add_buildings`(높이 상자, 기본 숨김).

## 목표와 성공 기준

신창 구역(site AOI `[126.155, 33.325, 126.19, 33.36]`)의 건물이 **높이 상자가 아니라** 실제 위치·윤곽 위에 지붕 형태·처마·난간·창호가 있는 건물로 보이고, 지붕은 실제 항공영상의 색과 무늬를 가진다. 흰 등대와 싱계물공원 정자는 사진을 참고한 모델로 같은 장면에 놓인다. 결과는 기존 단일 `var/rendering/local/scene.glb`로 웹(Three.js)과 Omniverse가 공유한다. 실제와 추정을 건물마다 기록하고 화면에 구분한다.

## 공통 제약

- 좌표 프레임(EPSG:32652/EPSG:3855, x=동·y=위·z=남, 1 m) 유지. 원천 윤곽·ID는 바꾸지 않는다.
- VWorld는 2D API(Satellite WMTS, 기존 `vworld_key`)만 쓴다. 3D 타일은 쓰지 않는다. 키는 산출물·로그에 남기지 않는다. 영상 출처 표기는 CREDITS에 둔다.
- Commons 사진(CC BY-SA 4.0)은 형태·비례 참고로만 쓰고 텍스처로 쓰지 않는다. CREDITS에 출처를 기록한다.
- 새 의존성 없음(PIL·numpy·trimesh·shapely 기존 사용). 원본 영상·타일·GLB는 `var/`(Git 밖).

## ① 절차적 건물

- **입력:** `var/rendering/site/scene.json`의 2,661개 윤곽과 속성(`height`, `grnd_flr`, `strct_cd`, `usability`, `archarea`).
- **높이(사용자 결정):** 원천 양수 높이 → `provider`. 없고 층수>0 → `층수×3.0 m`(`floors_estimated`). 둘 다 없으면 1층 3.5 m(`default_estimated`). ②의 DSM 높이가 생기면 덮어쓴다(`photogrammetry_measured`).
- **지붕 형태**(건물마다 `roof_rule` 기록):
  - **박공:** 최소 회전 사각형 대비 면적비 ≥ 0.85이고 주용도가 단독주택(01000)·창고(18000)·동식물(21000)이며 구조가 조적·블록·석조·경량철골·강파이프(11·12·13·32·33)이거나 속성이 없는 1층 건물. 용마루는 긴 축 방향. 경사는 주택 20°, 창고·동식물 10°. 처마 0.4 m.
  - **평지붕 + 난간 0.6 m:** 철근콘크리트(21)·다층·근린생활, 비사각형 윤곽.
  - 박공 벽은 윤곽 그대로 두고 지붕판은 사각형 기준으로 얹는다. 윤곽과 사각형 차이는 면적비 조건으로 제한한다.
- **지붕 영상:** AOI 안에서 건물 윤곽과 겹치는 VWorld Satellite **z19** 타일만 받는다. 기존 `prepare_imagery.py`의 타일 계산·수집 함수를 재사용한다. 건물별 지붕 영역을 잘라 한 장의 atlas(≤4096²)로 만들고, 지붕 정점은 EPSG:3857 위치로 atlas UV를 계산한다(위에서 투영).
- **외벽:** PIL로 만든 작은 절차적 텍스처(미장 벽+층별 창·문, 창고용 금속 골판, 현무암)를 미터 단위 UV로 반복한다. 층 수만큼 창 줄이 생긴다. 외벽 색·창 배치는 추정이다.
- **표시:** 기존 `buildings` 레이어를 대체하고 기본 표시로 바꾼다. 라벨은 "건물 위치·윤곽·지붕영상 실제 / 지붕형태·외벽·일부 높이 추정"이다. manifest `buildings.records[]`에 `height_status`·`roof_rule`·`roof_texture: vworld_z19`를 기록한다.

## ② 항공사진 사진측량 (사진 도착 후)

국토지리정보원 25 cm 프레임을 `var/aerial/ngii/`에 두면 `opendronemap/odm:gpu`(GPU0)로 DSM·정사영상·텍스처 메시를 만든다. 우리 z19 영상과 기존 DSM의 대응점으로 장면 프레임에 정합하고 오차를 기록한다. 건물별 `DSM 지붕 높이 − 지반`으로 높이를, 지붕면 평면 적합으로 평지붕/박공과 용마루 방향을 ①에 덮어쓴다. 텍스처 메시는 비교용으로만 둔다. 사진이 오기 전에는 구현하지 않는다.

## ④ 사진 참고 랜드마크

- **대상:** 흰 등대(Commons 신창 09), 싱계물공원 기와 정자와 육각정(Commons 신창 01).
- **위치:** z19 영상에서 찾은 좌표를 근거(타일 좌표·픽셀)와 함께 기록한다. 필요하면 VWorld 검색(2D) API로 POI 좌표를 교차 확인한다.
- **치수:** 사진 속 사람(1.7 m 가정)을 기준으로 비례 추정한다. 오차 약 ±10%이며 `dimension_basis`에 적는다.
- **모델:** 기존 `build.py` 터빈처럼 trimesh 코드 모델. 등대는 원통 몸체·전망대 난간·등롱·기단. 정자는 기둥·마루·겹처마 기와 우진각 지붕, 육각정. 재질 색은 사진 참고.
- 장면에는 `landmarks` 레이어로 넣고 manifest에 `status: photo_reference_estimated_geometry`, 출처 사진, 좌표 근거를 기록한다.

## 검증

- `build_local.py --self-test`: 원천 윤곽 ID 보존, 모든 건물의 높이 상태 기록, 박공·평지붕 판정 수, 지붕 UV가 atlas 안, 유한 geometry·normal, 기존 시설·지형 불변.
- 랜드마크 self-check: 좌표 → 장면 → 좌표 왕복 1 m 이내, 치수·근거 필드 존재.
- 브라우저 375/1280: 마을 시점에 박공·평지붕·창호가 보이고, 레이어·선택·가로 넘침·페이지 오류 정상. 스크린샷을 사람이 확인한다.
- GPU1 Kit으로 같은 GLB를 재캡처한다.
