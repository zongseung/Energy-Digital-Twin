# 기존 통합 장면에 건물·바다·관측 바람 추가

사용자 요청과 기존 현재 브랜치 구현 승인을 유지한다. 자료·좌표·높이를 보존하며 실제 계측과 시각화 추정을 구분한다.

- [ ] 실제 수집 건물 중 신창 일부의 양수 높이·경계로 입체화한다. 높이 미상은 제외하고 수량·DSM 기반 바닥 높이의 한계를 기록한다. WBM 해면의 형상은 유지하고 별도 수면 재질을 적용한다.
- [ ] 통합 화면에 건물·바다 레이어와 근접 시점을 연결한다. 시설21개 목록과 풍력·PV·지형·전력망 동작은 보존한다.
- [ ] Exa로 주변 실제 풍향·풍속 관측원을 검증한다. 접근 가능한 공공 관측이 있으면 Rust 캐시 API와 관측 시각/관측소/단위/지연 상태를 연결한다. 바람 방향 시각화는 관측소 기상이며 터빈 SCADA가 아님을 표시한다.
- [ ] 원천·경계·기하 self-test, 실제 브라우저와 실패/지연 상태, GPU1 RTX 캡처를 검증한다. 독립 검토 후 문서에 결과를 기록한다.

Ruling: 전체 제주 건물을 새로 처리하지 않고 이미 준비된 신창 부분 건물 데이터를 재사용한다. 건물 바닥은 DSM 기반 근사이며 실측 DTM으로 주장하지 않는다.
Ruling: 현재 관측의 유효성을 시각으로 판단한다. 검색에 나온 과거 값을 현재값으로 표시하거나 예보를 관측으로 대체하지 않는다.
