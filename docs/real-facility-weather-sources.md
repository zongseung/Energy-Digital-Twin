# 현재 장면 실제 시설·기상 원천 대장

확인일: 2026-09-30. 대상은 현재 통합 장면의 경도 126.145–126.40, 위도 33.31–33.435다. 이를 한경 행정구역 또는 독립 전력계통으로 확정하지 않는다. 이 문서는 원천 조사이며 형상 교체·기상 기능 구현 완료 보고가 아니다.

## 관측 기상: 지금 읽을 수 있는 것

공개 [제주 전체 AWS JSON](https://www.weather.go.kr/w/observation/land/aws-obs-data.do?db=MINDB_01M&stnId=0&sidoCode=5000000000)을 Python `urllib.request.urlopen`으로 인증 없이 GET하여 HTTP 200·43지점을 확인했다. 개수는 고정 계약이 아니다. 단위·기간은 [기상청 공식 도움말](https://www.weather.go.kr/wnuri_help/html/observation/aws-obs.jsp) 및 [공식 화면 JS](https://www.weather.go.kr/w/resources/js/app-2021/app-obs-climate-land-aws-obs.js?ver=202607091110)의 필드/표 머리 연결을 대조했다.

| 원천 필드 | 의미·단위 | 적용 주의 |
| --- | --- | --- |
| `awsTmp` | 기온 °C | 모듈/셀 온도가 아님. 실제 영하 기온을 일괄 결측 처리하지 않음 |
| `awsReh` | 상대습도 % | 유효범위 0–100. 일사량의 대체 관측값이 아님 |
| `awsPcpHr1` | 해당 시각 이전 60분 누적 강수량 mm | 5분마다 더하면 중복 계산. 일강수·강수강도와 구분 |
| `awsWs10`, `awsWd10` | 이전 10분 평균 풍속 m/s, 풍향 16방위 | 시설/허브높이 실측값이 아님. 불어오는 방향 |
| `tm`, `lat`, `lon`, `awsStnId` | 관측시각, 관측소 위치·번호 | 수신시각과 구분. 시설별 거리 재계산 필요 |

직접 조회한 한림 779 표본: `tm=202609301408`(KST), `lat=33.39268`, `lon=126.25809`, `awsTmp="25.4"`, `awsReh="79"`, `awsPcpHr1="0"`, `awsWs10="2.6"`, `awsWd10="북북서"`, `awsTroblKnd=""`. 이는 조사 시점의 단일 응답이며 최신값 보장은 없다. 같은 응답에 `awsPcpDay="-"`, 여러 필드의 null도 있었다. 일사 필드는 없었다.

원천의 `distance=0.0`은 시설까지 거리로 쓸 수 없다. 현재 등록점에서 한림 관측소까지 구면거리(R=6371 km)를 계산하면 도송 약 1.35 km, 한림 2.44 km, 명월 1.87 km다. 실제 필지 확인 후 다시 계산해야 하며, 일사 관측소 선택까지 한림으로 고정할 근거는 없다.

수집 확장 시 null·빈 문자열·`-`·비수치·비유한값·원천 sentinel을 결측으로 구분하고, 장애 표시·관측시각 파싱·미래/지연·요소별 유효범위를 검사한다. 이번 응답에서 추가 음수 sentinel 코드는 관측되지 않아 `-99` 같은 코드를 공식 확정하지 않는다. 결측 강수/일사를 0으로 바꾸지 않는다. 조사 후 기존 `src/weather.rs`/HTTP/WS에 nullable `temperature_c`, `relative_humidity_percent`, `precipitation_1h_mm`와 독립 `weather_status`를 추가하고 같은 관측소·시각의 값을 화면에 연결했다([구현 검증](../.omo/evidence/real-weather/implementation-evidence.md)). 기온 −90~60°C 검사는 앱의 합리성 범위이며 기상청 공식 QC가 아니다. 일사·실제 PV 제원·출력 검증은 미완료다.

## 일사: 공식 제공 확인과 미확보 자료

| 공식 원천 | 직접 확인한 내용 | 접근·운영 한계 |
| --- | --- | --- |
| [ASOS 시간자료 OpenAPI](https://www.data.go.kr/data/15057210/openapi.do) | 응답 명세에 선택항목 `icsr`(일사), 별도 `ss`(일조). `icsr=0.73`은 명세 예시 | 문서 열람만 수행. 서비스키 필요; 실제 제주 관측값으로 예시를 사용하지 않음 |
| [기상청 API Hub ASOS](https://apihub.kma.go.kr/apiList.do) | 시간자료 `SI` 단위 MJ/m², `SS` 단위 hr, `TM` KST. `authKey` 필수 | 명세 열람 성공; 인증 호출·실제 일사 시계열 수집 미수행 |
| [기상청 일사 관측 설명](https://www.kma.go.kr/down/t_policy/t_policy_200803.pdf) | 1시간 누적 일사량 MJ/m²와 1분 평균 W/m²의 구분을 명시 | 2008년 문서이므로 현재 지점별 제공 범위·실시간 지연의 근거로 쓰지 않음 |
| [ASOS 자료 포털](https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36) | 매정시 자료·일사 제공 안내. 지점/요소별 기간 차이, 전일자료 당일 10시 이후 안내 | 실제 후보 관측소의 일사 존재·연속성·이전 관측소 이력은 추가 검증 필요 |

1시간 누적 에너지 `H` MJ/m²의 구간 평균 일사강도는 `H × 1,000,000 / 3,600` W/m²다. 예컨대 1 MJ/m²이면 약 277.78 W/m²다. 원자료를 단순히 W/m² 또는 순간값으로 이름만 바꾸지 않는다. `/h`는 시간당 누적 구간을 설명할 수 있지만 API 원단위 MJ/m²와 별도로 기간을 기록한다. 일조시간을 일사량으로 읽거나 시간 일사량을 5분 실측값으로 복제하지 않는다.

포털은 기온·습도·기압·지면온도·풍향·풍속·일조 QC 0/1/9를 안내한다. 해당 목록에 일사는 없으므로 존재하지 않는 `icsrQcflag` 또는 모든 일사의 QC 통과를 가정하지 않는다. **현재 장면에 대응하는 실제 일사 시계열은 이번 조사에서 확보하지 못했다.** GHI/직달/산란의 구분, 누적 시작·끝, 야간 0과 결측, 날짜 경계, 원천 갱신 지연을 실제 샘플로 검증한 뒤 사용한다.

## 첫 실제 시설 채택에 필요한 최소 증거

1. 현재 장면 안의 PV 한 곳에 대해 등록 ID–정확한 지번/필지–현장 설비의 동일성을 확인한다. 도면 발행자·시설명·개정일·준공/설계 구분, 원본 URL/파일 해시·이용 조건을 보존한다.
2. 공식/운영자 도면 또는 위치·축척을 검증한 현장 자료로 배열 외곽, 패널 규격·수량·행 간격, 고정식/추적식, 진북 기준 방위각, 경사각, 설치높이를 확보한다. 확인하지 못한 치수는 별도 추정 표시한다. 사진·위성영상의 가시 외곽만으로 경사각과 후면까지 확정하지 않는다.
3. PV 출력 모델에는 시간·위치가 맞는 일사, 기온, 실제 용량/DC·AC 구분, 모듈 온도계수·열모델, 인버터·손실 근거가 필요하다. 습도·강수는 관측 환경 입력이며 검증 없는 임의 출력 저감계수를 만들지 않는다. 경사면 일사는 실제 방위·경사와 분해/전환 모델의 가정까지 기록한다.
4. 관측소 선택은 요소별 유효성·거리·고도·시각을 공개하고, 공간 대표성과 허브풍속/모듈온도 보정의 불확실성을 표시한다. 같은 시각의 시설 발전량 계측으로 검증하기 전 출력은 추정이다. 원천 장애·미확보 시 미확보로 남긴다.

## 재검증 기록

이번 확인 시나리오는 (a) 원천 GeoJSONL과 manifest의 세 ID·좌표·용량/null 대조, (b) 위 AWS URL의 무인증 GET와 `items`/필드 검사, (c) 공식 문서의 `icsr`, `SI`, `SS`, 단위·관측기간 확인이다. (a) 세 ID 일치, (b) HTTP 200·43행·일사 필드 없음, (c) 명세 열람 성공이 관찰되었다. 형상 도면 확보와 일사 시계열 확보는 성공 항목이 아니다. 이 파일에 조회 URL·표본·판정을 보존하며 별도 원문 파일을 새로 수집했다고 주장하지 않는다.
