# Weather WebSocket browser QA

2026-09-30 KST. Deployed local app at `http://127.0.0.1:8080/`; Chromium via omowright owned profile.

- [Live browser trace](../../var/verification/weather-ws/live-browser-qa.json): two 101 wind WebSocket handshakes; desktop first frame and next source poll frame each carry `station_count=43` and 43 station records. The source `received_at` moved from 18:33:35 to 18:34:35 UTC, exactly 60 seconds. CDP recorded zero weather HTTP GET requests during the desktop and mobile sessions. [Dedicated 71-second single-page trace](../../var/verification/weather-ws/live-long-qa.json) passed: three 43-row frames on one 101 socket, including two source timestamps 60 seconds apart, zero weather HTTP GETs, fresh UI at finish. The page showed fresh data and direction following for all 10 turbines.
- [Desktop screenshot](../../var/verification/weather-ws/live-1280-nakcheon.png) and [mobile screenshot](../../var/verification/weather-ws/live-375-stations.png) visually inspected. Selected Nakcheon 990 at 6.89 km, Hallim 779 at 1.35 km; all 43 rows include Chuja and Marado. At 1280 and 375 px, no horizontal overflow; buildings hidden as expected.
- [Mock socket browser QA](../../var/verification/weather-ws/mock-browser-qa.json) passed all 15 checks against the real renderer with only the wind socket substituted. Includes four cardinal directions against independently derived true north for all 10 nacelles, unchanged tower/foundation transforms, nearest station choices, calm/stale/closed socket behavior, opt-out and context loss. [Script](../../var/verification/weather-ws/mock-browser-qa.mjs).
- [Lifecycle unit fixture](../../var/verification/weather-ws/client-lifecycle.json) already passed 20 disconnect/reconnect cycles, stale socket callback exclusion, malformed frame, 15-second first-frame and 90-second silence deadlines.

- [Rotor browser QA](../../var/verification/weather-ws/rotor-browser-qa.json) passed against the deployed renderer with a mock wind socket and actual Three.js object transforms. With opt-in checked, 8 m/s Gosan rotors advanced about twice as fast as 4 m/s Nakcheon rotors while nacelles and towers stayed fixed. Eight repeat snapshots did not multiply animation speed. Below cut-in, at cut-out, stale, and closed-socket states stopped motion; fresh data and tab return resumed it. PV selection hid the estimate; the [375 px screenshot](../../var/verification/weather-ws/rotor-mobile.png) was inspected and had no horizontal overflow. Context loss stopped motion.

The live trace did not force a source outage; its disconnect and timeout behavior was exercised by the mock socket and lifecycle fixtures.
