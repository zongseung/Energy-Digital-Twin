데이터·추정 범위와 GPU 결과

탐라–한림 일부 실제 영상과 DSM 위에 풍력·PV·변전소·송전 구조를 함께 배치했습니다. 시점 버튼은 같은 장면 안에서 이동합니다. 범위 밖 시설과 경로는 표시하지 않습니다.

영상: 공간정보 오픈플랫폼(브이월드) Satellite. 촬영 기준일은 미확인입니다. 고도: Copernicus DSM / EGM2008, 약30m 원천을 약60m 간격으로 표시합니다. 건물·식생을 포함하며 세부 측량 자료는 아닙니다.

시설의 위치·경로는 원천 GIS입니다. 풍력 부품·철탑·전선 처짐·변전소 배치·PV 패널 배열은 추정 형상입니다. PV 등록 용량은 실측 발전량이 아니며, 동일 좌표의 다른 등록 기록이 있을 수 있습니다. 전기적 연결·흐름은 미확인입니다.

풍속 기반 추정은 가까운 기상청 지상 관측소의 10분 평균을 그대로 넣은 예시입니다. 허브 높이 풍속·실제 RPM·터빈별 출력이나 운전 상태가 아닙니다. 구형 Doosan WinDS3000/91 자료의 3/13/25 m/s 및 15.7 RPM을 잠정 가정하고, 미 에너지부 풍력 안내의 풍속 세제곱 관계로 3 MW까지 예시 출력을 계산합니다. 실제 제조사 출력곡선이나 탐라 현장 설정으로 확인된 값이 아닙니다. 정격 이하 회전은 일정한 날개끝 속도비 가정의 시각화이며, 0 RPM 표시는 실제 블레이드 정지를 증명하지 않습니다.

대화형 장면은 접속 기기의 WebGL로 표시합니다. 아래 PNG는 건물 비교 모형을 추가하기 전 통합 장면을 서버 GPU 1의 Omniverse RTX로 렌더한 정지 화면입니다. 실시간 스트리밍은 아닙니다.
