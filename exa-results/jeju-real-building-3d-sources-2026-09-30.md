# 제주 한경·한림 실제 건물 3D(형상·지붕·외벽 텍스처) 원천 조사

조사일: 2026-09-30
대상: 신창 풍차해안도로·탐라해상풍력 앞 해안·한림읍. 대략 lon 126.15–126.27, lat 33.33–33.42. 장면 원점은 126.17217, 33.3430267(EPSG:32652)이다.
기준선: Copernicus DSM + VWorld 위성영상 GLB, PostGIS 건물 윤곽 2,661건(양수 높이 623건), 건축물대장 표제부. 박스형 돌출 표현은 사용자가 거부했다.

표기: **[검증]**은 이번에 페이지·API·파일을 직접 받아 확인한 내용이다. **[2차]**는 비공식 출처나 언론에만 근거한 내용이고, **[추론]**은 확인한 사실에서 이끌어 낸 판단이다.

## 1) 결론 요약

- 이 구역에서 **실제 지붕 형태와 외벽·지붕 텍스처를 가진 건물 3D를 합법적으로 받아 GLB/OpenUSD로 바꿀 수 있는 기존 공개 원천은 확인되지 않았다.** 결과가 나오는 현실적인 경로는 **직접 촬영(드론 경사촬영 사진측량)**이다. 우리가 권리를 갖는 원본을 만들어야 한다.
- VWorld 공식 3D 지도에서 제주시 연동에는 실사 텍스처 LOD4 건물이 표시된다. 같은 방식으로 **신창리·한림읍에서는 3D 건물이 전혀 표시되지 않았다**(평면 영상만 있음, 2026-09-30 [검증]). 또한 VWorld 3D 자료는 약관상 공개제한 정보로, 저장·복제가 금지된다([검증]).
- 국가 3D 건물 중 제주 한경·한림에 해당하는 것은 **LoD1 박스(전국, 2021)**뿐이다. 이 자료도 공개제한이어서 보안심사나 안심구역을 거쳐야 쓸 수 있다([검증]). OSM은 이 구역 건물 576건 중 높이 0건, 지붕형태 0건이다([검증]).
- 차선책은 국토지리정보원 항공사진 원본 프레임이다. 25 cm, 종중복 60%·횡중복 30%, TIFF이고 무료이며 이용허락범위 제한이 없다. 이것으로 **지붕 형태와 지붕 텍스처**는 복원할 수 있을 가능성이 있다. 수직 촬영이어서 외벽 텍스처는 얻을 수 없다([추론]).
- 결정을 막는 미확인 사항은 네 가지다. ① 직접 만든 좌표 포함 3D 메시를 웹에 공개할 때 보안처리 의무가 있는지 ② 신창 해안 드론 비행승인과 촬영금지시설 해당 여부 ③ Google Photorealistic 3D Tiles의 제주 커버리지(있더라도 약관상 GLB 변환은 불가) ④ Mapillary 거리사진 커버리지(토큰 필요).

## 3) 원천별 상세 근거

### 3.1 VWorld

- **현장 표시 [검증, 2026-09-30].** 공식 WebGL 3D 지도 API 3.0을 프로젝트 키로 localhost에서 열었다. 카메라는 높이 350 m, 피치 −35°로 세 지점에 두었다. 결과는 아래와 같다.
  - 신창리(한경면사무소·신창초 주변): 항공영상만 지형에 입혀져 있고 벽면이 보이는 3D 건물이 없다.
  - 한림읍 중심(한림읍사무소·종합운동장 주변): 역시 평면 영상뿐이다.
  - 대조군 제주시 연동: 아파트·상가가 외벽 실사 텍스처를 가진 입체 건물로 표시된다.

  따라서 SDK 기본 레이어가 제주에서 텍스처 건물을 표시하는 것은 맞다. 한경·한림에는 그 자료가 없다. 첫 지점의 요청 기록에는 XDServer `tile`·`hybrid_bound`·`dem`과 TDServer POI만 나타났고 건물 레이어 요청은 없었다. 두 번째·세 번째 지점은 브라우저 리소스 타이밍 버퍼가 차서 요청 기록 대신 화면으로 판정했다. 약관을 지키기 위해 스크린샷은 확인 후 삭제했다.
  - 기존 `var/verification/vworld-probe/result.json`은 카메라가 바다를 향해 있었다. 요청 레이어도 `tile` 64건, `hybrid_bound` 65건, `dem` 23건뿐이어서 건물 판정 근거가 되지 못했다.
  - 이 확인에서 `docs/site-rendering.md`의 “해당 구역의 텍스처 포함 건물 모델 공급 여부는 미확인” 항목에 답이 나왔다. 공급되지 않는다.
- **구축 현황 [검증].** VWorld FAQ “3차원 건물은 어느기관에서 언제 구축했나요? (2022.10.11 기준)”에 따르면 LOD4 “3차원 시설물” 제주 항목은 서귀포시(2013)와 제주시(2014)이고, 구축기관은 국토교통부다. LOD3은 대구(2016), LOD1은 “전국 (일부 지역 제외)”(국토지리정보원, 2021)이다. 표에 “제주시”라고만 되어 있고 읍면 범위는 적혀 있지 않은데, 한림·한경에서는 실제로 표시되지 않았다. FAQ의 LoD 정의상 Level 4는 “3차원 실사모델, 지붕구조(경사면), 실사 영상 텍스처”이고 Level 1은 “블록 형태”다. https://www.vworld.kr/v4po_brdfaq_s001.do (FAQ 16801, 16800, 12358)
- **제공 형식과 절차 [검증].**
  - FAQ 22875: 3차원 공간정보 지원 포맷은 “3ds, jpg, img(3차원 입체모형, 수치표고모형)”이다.
  - FAQ 22877: “3차원 입체모형은 높이 값이 포함되어 공개제한 공간정보로 분류”된다. 공공은 보안관리규정 제16조에 따라 검토 후 제공하고, 민간 기업은 「국가공간정보 기본법」 제35조의2에 따른 보안심사를 거쳐 제공한다.
  - FAQ 10457: “브이월드 지도 내에 있는 3차원 데이터는 공개제한 공간정보이므로 저장이 불가”하다.
  - 오픈API 목록에는 2D 지도, 웹지엘 3D 지도, 국가중점데이터 API만 있다. 예전 “3D 데이터 API” 안내 페이지(`/dev/v4dv_3ddataintro_s001.do`)는 현재 빈 페이지다. https://www.vworld.kr/v4po_openapi_s001.do
- **약관 [검증].** 현행 약관과 2026-09-28 공지된 개정 약관(2026-10-30 시행) 모두 같은 내용을 담고 있다.
  - 제14조④5호: “3차원 공간정보는 관계 법령에 따라 공개제한 공간정보로 운영기관의 승낙 없이 무단으로 복제ㆍ유출하는 경우” 이용계약을 해지할 수 있다.
  - 제19조④: “서비스를 이용하여 얻는 정보를 사전 승낙 없이 복사, 복제, 변경, 번역… 사용하거나 이를 타인에게 제공할 수 없습니다.”
  - 제19조⑥: “사전 승낙 없이 데이터를 무단으로 저장하지 못합니다.”
  - 공지와 첨부 PDF: https://www.vworld.kr/v4po_brdnotice_s002.do (brdIde 34515)
- **참고 [2차].** 2019년 VWorld 운영기구는 xdo 파일을 저장하는 공개 코드에 삭제를 요청했다. 근거는 보안관리규정 제10조①3호였다. https://www.vw-lab.com/53

### 3.2 국토지리정보원·국토정보플랫폼

- **3차원 건물 모형 [검증].** 2021-06-29 보도자료 내용은 다음과 같다.
  - 전국 약 1,900만 동 “1단계 수준” 모형을 2021-06-30부터 제공한다.
  - “2차원의 건물 도형을 기반으로 건물마다 항공사진에서 건물의 높이를 관측”해 만들었고, “건물높이”와 “건물 지반 높이”를 제공한다.
  - “복잡한 건물의 형태, 재질 등이 표현되지 않”으며 “지붕의 형상” 분석에 한계가 있다.
  - “공개제한 자료로 … ‘공간정보 제공 신청서’ 작성 후 제공”한다.

## 4) 사람이 결정할 권고안

1. **직접 촬영(권장, 실사 결과가 나오는 경로).** 신창 풍차해안도로 등 우선 구간을 정해 드론 경사촬영과 GCP 기반 사진측량을 한다. 결과는 텍스처 메시이며 GLB/OpenUSD로 변환한다.
   - 사용자가 할 일:
     - 대상 범위를 확정한다.
     - 촬영 용역을 발주하거나 자체 촬영한다. 계약서에 원본 사진과 결과물 권리를 양도받는 조항을 넣는다.
     - 드론원스톱에서 촬영금지시설 확인과 비행승인을 신청한다.
     - 사람·차량 번호판이 찍힐 수 있으므로 개인정보 처리 방침을 정한다.
     - 공개 웹 뷰어에 좌표 포함 메시를 올리기 전에 보안처리 필요 여부를 국토교통부·국토지리정보원에 문의한다.
   - 비용과 기간은 이번 조사에서 확인하지 않았다.
2. **국토지리정보원 항공사진 원본 프레임(지붕만).** 한경·한림 최신 연도 25 cm 프레임을 무료로 발급받아 수직 사진측량을 한다. 지붕 형태와 지붕 텍스처, DSM을 얻을 수 있으나 외벽은 얻지 못한다.
   - 사용자가 할 일: 국토정보플랫폼 로그인 후 발급을 신청한다. 외부표정요소 제공 여부와 좌표 포함 결과물의 공개 가능 여부를 국토지리정보원에 문의한다.
3. **공개제한 LoD1과 높이 보강(박스이지만 높이 정확도 향상).** 보안심사는 공간정보사업자 또는 위치정보사업자여야 신청할 수 있고, 안심구역은 반출 심의를 거쳐야 한다. 텍스처는 얻지 못하므로 사용자의 목표에는 맞지 않는다.
4. **Google 3D Tiles 스트리밍 표시(변환 불가).** 사용자가 Google Maps Platform 키를 발급받아 제주 커버리지를 확인한다. 커버리지가 있으면 웹과 Omniverse에서 실시간 스트리밍으로만 표시할 수 있다. 우리 GLB/USD 장면의 원천으로는 쓸 수 없다.
5. **Mapillary 커버리지 확인(보조).** 사용자가 무료 토큰을 발급받아 신창 구간 사진 밀도와 촬영일을 확인한다. 외벽 보강 참고 정도로만 쓸 수 있다.

쓰지 말 것: VWorld 3D 타일 저장·변환(약관 위반), Google 타일 캐시·추출(정책 위반), AI Hub 영상을 장면 텍스처로 쓰는 것(학습 목적 한정), 카카오·네이버 3D·로드뷰(기존 판정).

## 5) 확인하지 못한 항목

- Google Photorealistic 3D Tiles의 한국·제주 한경·한림 커버리지. API 키가 필요하다.
- Mapillary 신창·한림 커버리지. 토큰이 필요하다. KartaView는 대조군이 실패했다.
- VWorld FAQ 표의 제주시 LOD4(2014)가 어느 읍면까지 포함하는지. 한림·한경 중심지에서는 화면상 표시되지 않았다.
- VWorld API 3.0에서 전국 LOD1 레이어를 별도로 켤 수 있는지. 기본 표시에는 나타나지 않았다.
- 국토지리정보원 항공사진의 한경·한림 최신 촬영연도, 프레임 목록, 외부표정요소 제공 여부와 등급.
- 보안관리규정 별표1(flSeq 144914683)이 2024-05 개정 현행본인지. 2026-06 입법예고 개정안의 최종 내용.
- 직접 만든 좌표 포함 3D 메시를 공개 웹과 Omniverse 결과물로 배포할 때 보안처리 의무가 있는지, 신창 해안 드론 공역과 비행승인 요건, 드론 촬영 비용과 기간.
- 제주도 디지털트윈 플랫폼의 3D 건물 수준과 외부 제공 여부. gis.jeju.go.kr 접속이 실패했다.
- LX “전국 아파트 외 건물 3D API”의 실제 형상 수준. 로그인과 승인이 있어야 내용을 볼 수 있다.

조사 방법 메모: VWorld 확인은 공식 WebGL 3D 지도 API 화면 조회 1회였다. 키는 환경변수로만 전달했고 출력물에서 가렸다. 타일·모델은 저장하지 않았고 스크린샷은 판정 후 삭제했다. Exa는 사용하지 않았고 WebSearch, WebFetch, curl, Overpass를 사용했다.
